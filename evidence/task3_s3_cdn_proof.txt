=== Схема работы ===

1. Пользователь нажимает Download Report в UI
2. Frontend → BFF (/api/reports с session cookie)
3. BFF → Reports API (с Bearer token)
4. Reports API проверяет S3 cache:
   - Если есть → возвращает {"source": "cache", "download_url": "http://localhost:8081/reports/user/report.json"}
   - Если нет → запрашивает из ClickHouse, сохраняет в S3, возвращает {"source": "olap", "download_url": "..."}
5. CDN (Nginx) отдаёт файл из MinIO S3 с кэшированием (max-age=3600)
