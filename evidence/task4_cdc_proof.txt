=== 4.6 Таблицы в ClickHouse (bionicpro) ===
customers         — staging, данные из CDC
orders            — staging, данные из CDC
telemetry         — staging, данные из CDC
kafka_customers   — Kafka Engine (consumer из crm.public.customers)
kafka_orders      — Kafka Engine (consumer из crm.public.orders)
kafka_telemetry   — Kafka Engine (consumer из crm.public.telemetry)
mv_customers      — MaterializedView: kafka_customers → customers
mv_orders         — MaterializedView: kafka_orders → orders
mv_telemetry      — MaterializedView: kafka_telemetry → telemetry
reports           — заполняется Airflow ETL
report_datamart   — витрина отчётности
etl_metadata      — метаданные ETL

=== Архитектура CDC pipeline ===

PostgreSQL (CRM)
    ↓ WAL (logical replication)
Debezium Connector (crm-connector: RUNNING)
    ↓ JSON events
Kafka Topics (crm.public.customers, crm.public.orders, crm.public.telemetry)
    ↓ consumed by
ClickHouse Kafka Engine (kafka_customers, kafka_orders, kafka_telemetry)
    ↓ parsed by
Materialized Views (mv_customers, mv_orders, mv_telemetry)
    ↓ inserted into
Staging Tables (customers, orders, telemetry)
    ↓ used by
Reports API → /reports endpoint
